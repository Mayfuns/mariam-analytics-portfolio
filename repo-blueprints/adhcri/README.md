# ADHCRI Health Intelligence Dashboard — Team HealthSync

A Power BI public-health analytics project developed for the **10Alytics Global Hackathon 2026**, analysing historical health indicators across **10 ASEAN countries**.

[View the portfolio case study](https://mayfuns.github.io/mariam-analytics-portfolio/adhcri.html)

## Project overview

The project brings fragmented ASEAN public-health indicators into one analytical model to support comparison across mortality, disease burden, nutrition, prevention, healthcare investment and workforce capacity.

### Headline scope

- **10 ASEAN countries**
- **1,691 valid records**
- **16+ health indicators**
- Historical coverage from **1990–2016**, depending on indicator
- Three-page Power BI dashboard
- SDG alignment: **3, 10 and 17**

## Dashboard pages

1. **ASEAN Public Health Overview**
2. **Disease, Nutrition & Child Health Risk**
3. **Healthcare Capacity & Investment**

## Tools

- Power BI
- Power Query
- DAX
- Star-schema modelling
- Data visualisation
- PowerPoint

## Data workflow

- Standardised country names
- Cleaned text and data types
- Unpivoted year columns
- Added indicator labels
- Appended multiple health datasets
- Built a fact table with Country, Year, Indicator and Value
- Modelled country, year and indicator dimensions

## Contribution

As part of Team HealthSync, my contribution focused on data preparation, transformation, modelling support, DAX/dashboard development, interpretation and presentation of the findings.

## Important limitation

The data is historical and should be interpreted as a trend-analysis dataset rather than a live 2026 surveillance system. The hackathon priority model is not an official public-health ranking.
