# Mariam Adetoyi — Data & BI Analyst Portfolio

A professional analytics portfolio showcasing case studies across healthcare, workforce, public health, retail and automotive data.

**Live portfolio:** https://mayfuns.github.io/mariam-analytics-portfolio/

## Selected case studies

- **VitalCare Health Group** — Power BI healthcare performance analysis covering operations, clinical outcomes and financial performance.
- **Talent Pulse Solutions** — Tableau and Excel workforce analytics focused on attrition and retention risk.
- **Global HIV Analytics** — Power BI analysis of long-term HIV burden, mortality and treatment trends from 2000–2024.
- **Lumina** — PostgreSQL healthcare analysis connecting operational, patient-outcome and financial questions.
- **Toy Store E-Commerce** — Power BI commercial analysis of sales, products, customers and time-based trends.
- **MotivaAutos** — SQL-driven automotive business analysis using relational querying and aggregation.

The portfolio also includes additional Excel and SQL projects covering Green Valley Medical Centre, Medcore Health Network, Northwind Analytics and DORI Risk Analysis.

## Core capabilities

- Power Query, DAX and data modelling
